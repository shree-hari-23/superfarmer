📚 Methodological Notes for Interviews & Audits

1. Why Top-3 Accuracy vs Top-1 Accuracy: In agronomic sciences, recommending a single crop is considered bad practice because farmers must account for seasonal market volatility, crop rotation, soil exhaustion, and local irrigation rights. A Top-3 recommendation provides the farmer with a primary cash crop, a soil-restorative pulse/oilseed, and a drought-resistant alternate.

2. LLM Reasoning vs Static Lookup: Traditional agronomy apps rely on static NPK lookup tables which break when weather shifts unexpectedly. SuperFarmer uses the flux-pro structured tier to dynamically reason over non-linear interactions between soil texture, rainfall variability, and micronutrient ratios.

3. Reproducibility: You can re-execute the automated evaluation suite directly from the command line at any time:
python evaluation/evaluate_crop_recommendation.py
python evaluation/evaluate_disease_diagnosis.py
